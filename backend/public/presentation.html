🚀 Problem & Solution

The Challenge

  • Disconnected recruitment process.
  • No real-time placement analytics.
  • Students lack personalized AI guidance.
  • Manual shortlisting is slow for employers.

The Solution

  • Unified 3-Tier Web Application.
  • AI-driven Match Scoring & Ranking.
  • Progressive Web App (PWA) for Mobile.
  • Live Institutional Data Dashboards.

⚙️ Tech Stack Architecture

Frontend Layer

HTML5, CSS3, JS: Core structure and styling with Glassmorphism.

Chart.js: Dynamic data visualization for analytics.

PWA: Service Workers for mobile app functionality.

Backend Layer

Node.js & Express: Scalable REST API architecture.

JWT Auth: Secure stateless session management.

MongoDB (Atlas): NoSQL database for flexible data schemas.

🧠 Core Algorithms

Weighted Recommendation

Formula: 70% Skills + 25% Academics + 5% Jitter.

Usage: Ranks jobs specifically for each student's profile.

NLP Suitability Analysis

Logic: Semantic string comparison using OpenAI GPT.

Usage: Extracts skills from PDF resumes and provides feedback.

* These algorithms ensure the platform goes beyond simple keyword matching.

    • 🗃️ Data Model (Schemas)

    User Model

    Stores name, email, role, and profile data like skills, cgpa, and department.

    Internship Model

    Stores title, description, domain, and employerId (Reference to User).

    Application Model

    Links student to internship. Stores status and matchScore.

    Feedback Model

    Stores user ratings and text reviews for platform improvement.

    🔑 Implementation Details

    🔐 Security (JWT)

    Tokens are signed on the server and stored in localStorage. Authenticated via authMiddleware.js.

    📁 File Uploads (Multer)

    Handles Resume and Avatar uploads. Files are served via static middleware with PDF content-type forcing.

    🔄 Live Updating: Institution dashboard uses 30-second polling to refresh numbers and charts automatically.

    ❓ Viva Preparation (Part 1)

    Q: How do you handle "No Internships found" for a user? A: I added an empty state handler in students.html that prompts the user to add more skills or refresh their token if it has expired. Q: Why did you use a 30-second auto-refresh? A: To provide real-time visibility to institutions during placement drives without requiring the user to manually reload the page.

    ❓ Viva Preparation (Part 2)

    Q: How does the PDF Resume preview work? A: I implemented a custom Express middleware for the /uploads route that forces the Content-Type to 'application/pdf', ensuring it opens in the browser. Q: How do you prevent Chart.js from crashing on data refresh? A: I store chart instances in a tracking object and call .destroy() on existing charts before creating new ones with fresh data.
